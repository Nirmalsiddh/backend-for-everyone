# Taskforge

## Problem

Beginner/frontend developers can build interfaces but often get blocked when they need to create databases, CRUD APIs and backend integration.

## Intended user

Student, beginner developer, frontend developer, or solo builder.

## Hackathon concept

Backend for Everyone: a small, plain-language path through an existing backend platform.

## Pre-existing work

The underlying BaaS/backend platform existed before Taskforge. It includes project management, PostgreSQL connections, schema application, CRUD runtime, API keys, authentication, a dashboard and advanced capabilities.

## Taskforge work

H1 adds a Guided Builder route (`/projects/:projectId/guided`), a fixed Task Manager flow, plain-language choices, review and preview views, and accessibility-focused labels, keyboard controls, focus handling and scoped styles. Project navigation links to the builder and is simplified while viewing it.

## Current limitation

H1 is UI/preview only. Choices live in component state and reset on reload. The builder makes no network requests, checks no live database status and creates no backend resources. Database settings remain an existing, separate page.

Real schema application and CRUD configuration belong to H2. No API URL or credentials are generated by H1.
